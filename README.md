# Прототип UI бенчмарков навигатора

## Вариант A: без Python и без Node (Windows)

В папке проекта выполните:

```powershell
cd $env:USERPROFILE\.cursor\navigator-bench-ui
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

В браузере откройте: **`http://127.0.0.1:8080/standalone.html`**

Это **один HTML-файл** в стиле нового админ-интерфейса (светлый фон, фиолетовые шапки таблиц): главная, карточка бенча с пагинацией и цепочкой версий, запуски, упрощённые модалки. **Без Node/npm.** Данные и «сохранения» только в памяти вкладки (после F5 — снова демо).

Полная логика (контекст, новые версии на каждое действие, все поля запуска) остаётся в **React** (`npm run dev`), когда почините доступ к registry.

Другой порт: `.\serve.ps1 -Port 9090`

**Ещё проще:** откройте файл `standalone.html` двойным щелчком в Проводнике (часто работает; шрифты подтянутся с Google, если есть интернет).

## Вариант B: Python (если установите Python)

```powershell
cd $env:USERPROFILE\.cursor\navigator-bench-ui
python -m http.server 8080
```

Браузер: `http://localhost:8080/standalone.html`

Навигация в standalone — через hash (`#/runs`, `#/bench/b1` и т.д.).

## Вариант C: Vite + React (горячая перезагрузка)

Требуется установленный Node.js и npm.

```powershell
cd $env:USERPROFILE\.cursor\navigator-bench-ui
npm install
npm run dev
```

Откройте адрес из вывода Vite (обычно `http://localhost:5173`).

## Что в интерфейсе (прототип)

- Главная: таблица бенчмарков (название, **текущая версия**, число тасок, дата версии), **Запуск** и **Создать**; создание — модалка имени, переход в карточку.
- Карточка: метаданные, цепочка **v1 → v2 → …** (просмотр старых версий read-only), таблица тасок с **пагинацией 20**, сортировка **web_name**, **task_id**, свитч «архивные», **Добавить / Изменить / В архив / Восстановить**, подтверждение новой версии при необходимости, **Запуск всего** / **выбранных** с модалкой параметров.
- Стилистика: светлый фон, фиолетовый `#2d1b4e` шапка таблицы, скругления как в референсе админки.
